> 大学诸事，尽入一册。

把群聊通知、截图和课表里的零散信息，变成能执行、会提醒的校园事项。

**弦歌册**是一款面向大学生的校园事项助手。它把课程、任务、考试、习惯、成绩与提醒放在同一个清晰的入口中，帮助你从“看到通知”走到“完成事情”。应用坚持本地优先：课程和日常记录默认只保存在设备上；需要识别图片或整理长通知时，再由你主动选择并配置 AI 服务。

---

## 核心功能

### 今日

教学周进度、今日课程、上课状态与完成情况一目了然。已经结束的课程会自动收起，正在上的课程突出显示；任务支持「全部 / 7 天内 / 逾期 / 无日期」筛选，顶部可快速搜索和新增。

### 收件

接收系统分享的图片与文字，先形成可编辑草稿，再由你确认是否写入课程或日程。图片识别默认通过你配置的多模态 AI 完成；不支持图片的模型仍可用于文字整理，识别失败时原文会保留，不会丢失。

### 课程

可切换教学周的七天课表、按天列表、空白节次快捷加课与时段冲突提示。课程卡片优先显示课程名、楼栋和教室，点击可查看详情、复制地点或补充作业与考试。支持 **PDF / HTML / Excel / 课表口令**导入，并在写入前展示新增、重复和信息缺失项。

### 厚积

习惯打卡与连续记录，年度热力图，沉淀每日坚持。每日箴言陪伴你积跬步以至千里。

### 百宝

成绩与加权平均分、考试倒计时、计算器（科学计算与单位换算）、专注番茄钟、生活费记账等校园小工具，按需取用。

### 我的

提醒诊断、外观主题、本地备份恢复、每日箴言、AI 服务配置等设置。

## 数据与隐私

弦歌册尊重并保护你的隐私。所有业务数据（课程、任务、事件、习惯、成绩、备份）均以 Room 数据库存储在**本机设备**，不主动上传到弦歌册自建服务器。

- 应用不主动扫描相册，只读取你明确选择或分享的内容。
- 图片识别不依赖弦歌册自建服务器；只有在你配置并主动调用 AI 服务时，相关图片或文字才会发送给你选择的第三方接口。
- Android 系统自动云备份已禁用。
- AI 功能默认关闭；启用后，仅在你主动触发时才会把文字发送到你配置的服务商，本应用不经手任何第三方服务器。
- API 密钥使用 Android Keystore 与 AES-GCM 加密保存，不写入日志、备份或源代码。

## 隐私政策

**更新及生效日期：2026 年 8 月 1 日**

弦歌册（包名 `win.iqwqi.xiangece`，版本 0.0.1）是一款单人、本地优先的校园事项助手。本政策说明应用如何处理你的信息。

### 我们处理的信息

- 你主动输入或分享的通知文字、截图和课表图片。
- 你创建的课程、任务、校园事件、习惯、成绩、学期、节次与提醒设置。
- 你主动配置的 OpenAI 兼容接口地址、模型与 API 密钥。

弦歌册不会主动扫描相册，不读取通讯录、通话记录、短信、位置或其他应用的使用情况。

### 本地处理

弦歌册以「本地优先」为原则。所有业务数据均以 Room 数据库存储在设备本地，不主动上传弦歌册自建服务器。图片会复制到应用私有目录，以避免分享临时链接失效；是否交给第三方 AI 识别完全由你决定。

Android 系统自动云备份已禁用。你可以主动导出 `.xiangece` 本地备份文件，备份包含收件图片副本但不包含 API 密钥。

### 可选 AI

AI 增强默认关闭。启用后，每次发送前都会提示：将把当前 OCR 文字与必要的学期上下文发送到你配置的第三方接口，不发送原图。数据如何被第三方处理取决于该接口提供者的政策。

API 密钥使用 Android Keystore 与 AES-GCM 加密保存，不写入日志、备份或源代码。

### 权限

- **通知权限**：用于课程、任务、事件提醒与番茄钟完成提示；Android 13 及以上需主动授权，拒绝后其他功能仍可使用。
- **图片选择**：仅处理你明确选择或分享的图片，不主动扫描相册。
- **网络**：仅用于你主动启用的 AI 接口，以及打开本页面；未配置 AI 时核心课表和记录功能可离线使用。
- **开机完成**：设备重启后恢复已设置的提醒。
- **振动**：提醒触发时短振动提示。

### 备份与导出

Android 自动云备份已被禁用。你可主动导出包含收件图片副本的 `.xiangece` 备份并自行保管；备份不包含 API 密钥。

### 数据删除

卸载弦歌册会删除其应用私有目录和本地数据库，也可在系统设置中清除应用数据。已导出的 `.xiangece` 文件由你自行管理。

### 儿童与未成年人

弦歌册面向大学校园场景，不以儿童为目标用户。未成年人应在监护人指导下使用第三方 AI 服务。

## 为什么做它

大学里的重要信息经常散落在群聊、教务系统、截图和临时通知里。弦歌册不试图替代所有应用，而是把这些零散信息收束成一张能查看、能修改、能提醒的个人校园清单。

它没有账号体系、广告和强制云同步，适合先从自己的课表开始使用；如果你愿意，也可以通过课表口令或备份文件与同学交换结构化课表。
