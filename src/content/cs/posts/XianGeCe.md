> 大学诸事，尽入一册。

把群聊通知、截图和课表里的零散信息，变成能执行、会提醒的校园事项。

**弦歌册**是一款面向大学生的**本地校园事项助手**。它以「本地优先」为原则：所有数据存储在你的设备上，不主动上传任何服务器；AI 功能默认关闭，由你主动配置与开启。课程、任务、事件、习惯、成绩、提醒，尽入一册。

---

## 核心功能

### 今日

教学周进度、下一节与当天课程一目了然。任务支持「全部 / 7 天内 / 逾期 / 无日期」筛选，并显示课程归属与最近提醒；顶部全局搜索，一键快捷新增。

### 收件

接收系统分享的图片与文字，在本地完成中文 OCR 识别，识别失败可离线重试。未确认的收件不会写入课程或日程，由你亲自确认后再收录。

### 课程

可切换教学周的七天课表、按天列表、空白节次快捷加课、时段冲突提示。支持 **PDF / HTML / Excel / 口令**导入，以及可选的 AI 截图识别。

### 厚积

习惯打卡与连续记录，年度热力图，沉淀每日坚持。每日箴言陪伴你积跬步以至千里。

### 百宝

成绩 GPA 计算、考试倒计时、专注番茄钟、生活费记账等校园小工具，按需取用。

### 我的

提醒诊断、外观主题、本地备份恢复、每日箴言、AI 服务配置等设置。

## 数据与隐私

弦歌册尊重并保护你的隐私。所有业务数据（课程、任务、事件、习惯、成绩、备份）均以 Room 数据库存储在**本机设备**，不主动上传任何服务器。

- 应用不主动扫描相册，只读取你明确选择或分享的内容。
- 图片文字识别使用应用内捆绑的中文 OCR 模型，在**设备本地**完成。
- Android 系统自动云备份已禁用。
- AI 功能默认关闭；启用后，仅在你主动触发时才会把文字发送到你配置的服务商，本应用不经手任何第三方服务器。
- API 密钥使用 Android Keystore 与 AES-GCM 加密保存，不写入日志、备份或源代码。

## 隐私政策

**更新及生效日期：2026 年 8 月 1 日**

弦歌册（包名 `win.iqwqi.xiangece`，版本 0.0.2）是一款单人、本地使用的校园事项助手。本政策说明应用如何处理你的信息。

### 我们处理的信息

- 你主动输入或分享的通知文字、截图和课表图片。
- 你创建的课程、任务、校园事件、习惯、成绩、学期、节次与提醒设置。
- 你主动配置的 OpenAI 兼容接口地址、模型与 API 密钥。

弦歌册不会主动扫描相册，不读取通讯录、通话记录、短信、位置或其他应用的使用情况。

### 本地处理

弦歌册以「本地优先」为原则。所有业务数据均以 Room 数据库存储在设备本地，不主动上传任何服务器。图片文字识别使用应用内捆绑的中文 OCR 模型在设备本地完成，图片会复制到应用私有目录以避免分享临时链接失效。

Android 系统自动云备份已禁用。你可以主动导出 `.xiangece` 本地备份文件，备份包含收件图片副本但不包含 API 密钥。

### 可选 AI

AI 增强默认关闭。启用后，每次发送前都会提示：将把当前 OCR 文字与必要的学期上下文发送到你配置的第三方接口，不发送原图。数据如何被第三方处理取决于该接口提供者的政策。

API 密钥使用 Android Keystore 与 AES-GCM 加密保存，不写入日志、备份或源代码。

### 权限

- **通知权限**：用于课程、任务、事件提醒与番茄钟完成提示；Android 13 及以上需主动授权，拒绝后其他功能仍可使用。
- **精确闹钟**：Android 12 及以上用于保证提醒准时触发，未授予时系统可能延迟提醒。
- **存储权限**：保存课表截图、导出备份文件与缓存识别结果。
- **相机 / 相册**：拍摄或选择课表图片进行 OCR 识别，仅本地处理。
- **网络**：仅用于你主动启用的 AI 接口，以及打开本页面。
- **开机完成**：设备重启后恢复已设置的提醒。
- **振动**：提醒触发时短振动提示。

### 备份与导出

Android 自动云备份已被禁用。你可主动导出包含收件图片副本的 `.xiangece` 备份并自行保管；备份不包含 API 密钥。

### 数据删除

卸载弦歌册会删除其应用私有目录和本地数据库，也可在系统设置中清除应用数据。已导出的 `.xiangece` 文件由你自行管理。

### 儿童与未成年人

弦歌册面向大学校园场景，不以儿童为目标用户。未成年人应在监护人指导下使用第三方 AI 服务。
